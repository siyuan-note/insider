## 思源笔记测试通道

思源笔记独立的 Insider 内部预览机制已经废除。在包含更新通道设置的新版本中，可在`设置 - 关于 - 更新通道`中选择：

- Stable：仅接收正式版。
- Beta：接收正式版、RC 和 Beta。
- Alpha：接收正式版、RC、Beta 和 Alpha。

默认使用 Stable。Beta 和 Alpha 直接连接 GitHub，因此需要能够访问 GitHub。详情请参考 [siyuan-note/siyuan#18366](https://github.com/siyuan-note/siyuan/issues/18366)。

**测试预发布版本前请务必先备份数据！**

预发布测试问题请在[思源笔记主仓库](https://github.com/siyuan-note/siyuan/issues)反馈。本仓库仅保留历史资料，不再发布 Insider 版本。
