## SiYuan Test Channels

The separate SiYuan Insider Preview mechanism has been retired. In SiYuan versions that include the new update channel setting, select a channel under `Settings - About - Update channel`:

- Stable receives stable releases only.
- Beta receives stable, RC, and Beta releases.
- Alpha receives stable, RC, Beta, and Alpha releases.

Stable is the default. Beta and Alpha connect directly to GitHub and therefore require access to GitHub. See [siyuan-note/siyuan#18366](https://github.com/siyuan-note/siyuan/issues/18366) for details.

**Be sure to back up your data before testing prerelease versions!**

Please report prerelease testing issues in the [main SiYuan repository](https://github.com/siyuan-note/siyuan/issues). This repository is retained for historical reference and will no longer publish Insider releases.
